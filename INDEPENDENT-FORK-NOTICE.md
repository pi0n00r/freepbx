# Independent project boundary

`pi0n00r/freepbx` is an independent integration and release project for
deployments built on FreePBX and Asterisk. It is not an official FreePBX fork,
does not contain the upstream FreePBX source tree, and is not affiliated with,
sponsored by, or endorsed by Sangoma Technologies or the FreePBX project.

The repository may carry independently maintained adapters, declarative
component locks, verification tools, a source-only telephony integration backup
and narrowly scoped compatibility patches.
Each retained component must identify its exact files, upstream compatibility,
activation boundary and verification contract. Private configuration and
credentials remain outside the public repository.

FreePBX and related names are used solely to identify compatibility with the
upstream software. Their respective copyrights, licences and trademarks remain
with their owners. Fleet-authored additions declaring AGPL-3.0-or-later are
licensed under those declared terms; pre-existing files retain their recorded
history and any file-specific notices.
